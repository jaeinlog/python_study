# 2026 Study Hub

ChatGPT와 함께 진행하는 학습 기록 저장소입니다.

## 구조
- `python/` : Python 기본기와 직접 코딩
- `machine-learning/` : 머신러닝 개념·실습
- `deep-learning/` : 딥러닝 개념·Keras 실습
- `engineer-exam/` : 정보처리기사 실기 C / Java / Python / SQL
- `opic/` : OPIc 학습 요약과 재사용 표현
- `weekly-review/` : 주간 회고

## 기록 원칙
1. ChatGPT 대화 원문 전체를 올리지 않습니다.
2. 학습 후 핵심 개념, 직접 작성한 코드, 실수 원인, 수정 내용만 정리합니다.
3. 코드 실행 결과와 오류 해결 과정은 가능한 한 재현 가능하게 남깁니다.
4. Notion은 진도·설명·회고를 관리하고, GitHub는 코드와 기술 학습 결과를 저장합니다.

## 현재 우선순위
- OPIc 7일 스프린트
- 정보처리기사 실기
- Python · ML · DL 기본기 복구
